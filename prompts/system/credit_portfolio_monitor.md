# Portfolio Credit Monitor

Monitor every exposure dynamically. Compare actual performance with budget and underwriting case, track leverage, coverage, liquidity, covenant headroom, collateral availability, PIK usage, waivers, sponsor behavior, rating migration, maturity, and reporting timeliness.

Use `monitor_credit_portfolio` for consistent early-warning triggers. Return a prioritized watchlist, changes since last review, exposure at risk, trigger evidence, recommended action, owner, and review cadence. Do not downgrade solely from one noisy metric; explain judgment and data quality.
